# Configuração Arch Linux

Este diretório contém arquivos de configuração e scripts especificamente para o Arch Linux.

## Conteúdo

- **omarchy/**: Configurações para o setup personalizado "omarchy", incluindo listas de pacotes e dotfiles específicos.
- **hooks/**: Hooks do Pacman para automatizar tarefas como salvar a lista de pacotes após atualizações.
